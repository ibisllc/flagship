## Part F: Firebase Cloud Messaging for Android pushes (do this BEFORE Part B)

Android bundles are rebuilt after F2, so Part B waits until the owner says the new bundles are ready.

Never open, read, copy or paste the contents of a downloaded key file, and never type a key into any page or chat.

1. Open https://console.firebase.google.com/ with the owner's Google account (the one that owns the Play Console
   app). If a project for Flagship already exists, ask the owner whether to use it; otherwise **Add project**:
   name `Flagship`, **Google Analytics off**, Create.
2. Note the **Project ID** (Project settings → General). It is not secret; tell the owner.

### F2. The Android app and its config file
1. Project settings → General → **Add app** → Android. Package name: `com.flagshipserver.app` (exactly). Nickname:
   `Flagship Android`. Leave the SHA-1 empty (not needed for messaging). **Register app**.
2. **Download google-services.json**. Then STOP and call the owner: "google-services.json is downloaded. Please move
   it to `~/flagship/apps/mobile/android/app/google-services.json` (replacing the placeholder there) and tell Claude
   Code in the terminal to rebuild the Android bundles." Skip the remaining SDK steps of the wizard (the app already
   has the code): Next, Next, Continue to console.

### F3. Messaging is on
Project settings → **Cloud Messaging**: "Firebase Cloud Messaging API (V1)" must say **Enabled**. If it says
disabled, use its menu to open the Google Cloud console page and **Enable** it. Ignore the legacy API.

### F4. A key for Flagship's server (least privilege)

   (check the project picker at the top shows the Firebase project).

   continue. Role: **Firebase Cloud Messaging API Admin** (only this role). Continue, Done.

4. STOP and call the owner with exactly this: "The FCM key file has downloaded. In the terminal, run these two
   commands (the second asks for the Project ID: type `<Project ID from F1>`), then delete the downloaded file:"
   ```
   cd ~/flagship-0.4/apps/com && npx wrangler secret put FCM_SERVICE_ACCOUNT_JSON < ~/Downloads/<the downloaded file>.json
   ```
