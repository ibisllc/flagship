Your server recipe is ready

✓

A recipe is a tiny signed file — your phone authorized it, and only your phone can. Get it into the Assembler, then build your boot USB.

1 Your recipe for your server

Two ways to hand it to the Assembler — pick whichever fits:

Copy if the Assembler is on this computer — nothing touches the disk. Download if you'll carry it to another machine.

2 The Flagship Assembler

The desktop app that writes your boot USB. It bakes the recipe inside a stock Linux installer image — no balenaEtcher, Rufus, or dd needed.

You only install the Assembler once. Reuse it for every server you ever set up — just feed it a fresh recipe each time.

3 Assemble & boot

Open the Assembler, give it this recipe (paste it, or open the downloaded file) + a recommended Linux image + a USB drive, and hit Assemble. Boot the target machine from the USB — the rest is automatic, ending at a real green padlock on your domain.
