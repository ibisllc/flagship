A recipe is a tiny signed file — your phone authorized it, and only your phone can. Two steps from here: get the Assembler (once), then assemble your boot USB.

1 Your recipe (.json)

The signed install ticket for your server. Keep it private; it's single-use and expires.

2 The Flagship Assembler

The desktop app that writes your boot USB. It bakes the recipe inside a stock Linux installer image — no balenaEtcher, Rufus, or dd needed.

You only install the Assembler once. Reuse it for every server you ever set up — just feed it a fresh recipe each time.

3 Assemble & boot

Open the Assembler, drop in this recipe + a recommended Linux image + a USB drive, and hit Assemble. Boot the target machine from the USB — the rest is automatic, ending at a real green padlock on your domain.
