Build a Flagship server

Enter the build code your phone gave you. Your phone holds the keys; this page just assembles the installer.

1. Build code

From the Flagship app: Create a new server → Save.

Don't have the app yet? Use the phone simulator to mint a code.

2. Redeem the code

Calls /api/build-tickets/redeem to fetch the signed install blob.

3. Download & personalize the ISO

Streams the base ISO from the CDN, appends the trailer, saves to disk.

4. Done

Flash the .iso to a USB stick (Balena Etcher, Rufus, dd), boot the target machine, the rest is automatic.
