Flagship Studio · 特許出願中

コンピューターからサーバーを作りましょう。

Studio は Flagship アプリとペアリングし、スマートフォンが承認したサーバーのレシピを受け取り、起動用 USB を書き込みます。

サーバーを作成するのに使う Mac、Windows、Linux のコンピューターで flagshipserver.com/studio を開いてください。

このコンピューターにおすすめ macOS 版をダウンロード Apple シリコンと Intel · DMG このコンピューターにおすすめ Windows 版をダウンロード 試験運用 Windows 11 または Windows 10 22H2 · ZIP · すべての PC での動作はまだ確認されていません このコンピューターにおすすめ Linux 版をダウンロード 試験運用 x86-64 · AppImage · Node.js 22 以降、pkexec、xorriso が必要
  1. Studio をインストールして開きます。

    Studio に QR コードと短いペアリングコードが表示されます。

  2. スマートフォンからペアリングします。

    Flagship アプリ（App Store · Google Play）で「サーバーを追加」→「Studio とペアリング」を選び、QR をスキャンするか短いコードを入力します。

  3. USB に書き込んで起動します。

    Studio で書き込み先のドライブを選びます。スマートフォンがレシピを承認し、OS イメージと USB は Studio が処理します。

Web アプリからレシピをダウンロード済みですか？Studio で開くか貼り付けてください。
