Flagship Studio · Patente solicitada

Crie seu servidor a partir do seu computador.

O Studio é pareado com o app do Flagship, recebe a receita do servidor que seu celular autorizou e grava o USB de boot.

Abra flagshipserver.com/studio no computador Mac, Windows ou Linux que você vai usar para criar o servidor.

Recomendado para este computador Baixar para macOS Apple Silicon e Intel · DMG Recomendado para este computador Baixar para Windows Experimental Windows 11 · ZIP · ainda não comprovado em todos os PCs Recomendado para este computador Baixar para Linux Experimental x86-64 · AppImage · precisa do Node.js 22 ou mais recente, pkexec e xorriso
  1. Instale e abra o Studio.

    O Studio mostra um código QR e um código de pareamento curto.

  2. Pareie pelo seu celular.

    No app do Flagship (App Store · Google Play), escolha Adicionar servidor → Parear com o Studio e depois escaneie o QR ou digite o código curto.

  3. Grave o USB e dê boot por ele.

    Escolha a unidade de destino no Studio. Seu celular aprova a receita; o Studio cuida da imagem do sistema operacional e do USB.

Já baixou uma receita pelo app web? Abra ou cole no Studio.
