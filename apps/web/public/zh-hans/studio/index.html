在你的电脑上构建服务器。

Studio 与 Flagship 应用配对，接收你的手机授权的服务器配方，并写入启动 U 盘。

请在你将用来创建服务器的 Mac 或 Windows 电脑上打开 flagshipserver.com/studio。

推荐用于此电脑 下载 macOS 版 Apple 芯片和 Intel · DMG 推荐用于此电脑 下载 Windows 版 实验性 Windows 11 · ZIP · 尚未在所有电脑上验证
  1. 安装并打开 Studio。

    Studio 会显示一个二维码和一个简短的配对码。

  2. 用手机配对。

    在 Flagship 应用（App Store · Google Play）中选择“添加服务器”→“与 Studio 配对”，然后扫描二维码或输入短码。

  3. 写入 U 盘并启动。

    在 Studio 中选择目标驱动器。你的手机批准配方；操作系统镜像和 U 盘由 Studio 处理。

已经从网页版下载了配方？请在 Studio 中打开或粘贴它。使用 Linux？获取 AppImage 实验性（x86-64；需要 Node.js 22 或更高版本）。
