你卡住了。先试试这些。

针对我们最常遇到的四类问题的快速解决办法。如果都没用，请滚动到页面底部，给真人发邮件。

快速开始

我只想开始。

  1. 从 /download 安装手机应用（或使用网页版）。
  2. 在电脑上安装 Flagship Studio。
  3. 在应用中创建服务器，用 Studio 的二维码或短码完成配对，然后用 Studio 写入安装 U 盘（8 GB 以上）。
  4. 服务器第一次请求批准时，请确认其屏幕上的 6 位代码与应用中的一致，然后再批准。

大约十分钟后，你就会在 you.flagship.services 上看到真正的绿色小锁。

卡在安装环节

我卡在了安装界面。

  1. “配对码未被接受”：重新打开 Studio 以显示新的二维码和短码，然后再试一次。
  2. “无网络”：安装程序需要有线以太网口上的 DHCP。安装期间不支持 Wi-Fi，请插上网线。
  3. “磁盘太小”：最低要求为 32 GB。安装程序会格式化你指定的磁盘，不支持双系统。
  4. 6 位代码不一致：不要批准。你屏幕上的服务器并不是你的手机正在通信的那台。请在应用中删除该服务器，然后用新的配方重新创建。

还是卡住？请截图并通过邮件发给我们。

手机问题

我的手机坏了。

  1. 如果你设置了云端恢复，在新手机上用你的账户名登录。它会要求你的通行密钥（由 iCloud 钥匙串或 Google 密码管理器保存）和恢复密码短语。
  2. 没有云端恢复？请使用另一台仍处于登录状态的设备，或你保存的账户密钥文件。如果这些都没有，你的账户就无法恢复；这是有意为之（我们没有后门），我们在设置过程中也尽量说得很清楚了。
  3. 硬件本身没问题。用同一个盒子新建账户，相当于一次干净的重装。

完整恢复流程：/docs/recovery。

服务无法加载

某个服务加载不出来。

  1. 浏览器显示“DNS 错误”：你的子域名正在传播。请等待 60 秒，并查看 /status。
  2. “证书无效”/没有绿色小锁：守护进程正在续期。请在控制台查看“正在续期”标记，通常 90 秒内会恢复。
  3. “403 非成员”：该服务受身份保护，而你的手机尚未批准你的设备。请在手机上批准，然后刷新。

服务器最近的事件可在应用的“活动”中查看。

按症状再多说几句。

有三件事可能让原本正常的安装掉线。多数情况下它们会自行恢复；如果没有，请看下面该查哪里。

我的安装卡在“已安装”

安装完成后，盒子关机以便你拔下 U 盘再开机，但之后它一直起不来。这几乎总是意味着盒子在启动早期连不上网络，因而无法取得解锁其加密磁盘的密钥。这是仅有 Wi-Fi 的盒子上的常见症状（磁盘解锁步骤在 Wi-Fi 可用之前就会运行）。有两种解决办法：

  1. 插上以太网线。有线连接建立得足够早，盒子能取得解锁密钥并完成启动。这是最简单的办法，磁盘依然保持加密。
  2. 或者新建一台关闭磁盘加密的服务器。在应用（或网页版）的“创建服务器”界面取消勾选加密磁盘，然后重新写盘。磁盘未加密的盒子启动时无需联网解锁，因此在仅有 Wi-Fi 的环境中也能工作。代价是你的数据在静态时不再加密，盒子被盗时安全性较低。只有在无法使用有线连接时才选择这种方式。

控制台显示“离线”

从你的盒子到 flagship.services 的隧道断了。请依次检查：

  1. 电源和网络。盒子开着吗？网线插好了吗？能访问互联网吗（ping 1.1.1.1）？
  2. 出站 443 可达。某些限制严格的网络会阻断长连接 WebSocket。在盒子上运行 curl https://flagship.services/api/health 应当返回 JSON。
  3. 守护进程状态。在应用中从服务器页面重启服务器。如果你开启了调试访问（从服务器页面添加的一个限时 SSH 密钥），就可以通过 SSH 登录并运行 systemctl status flagship；近期日志见 journalctl -u flagship -n 200。

“此服务器的密钥已更改”

你的手机从你第一次批准某台服务器起，就保存了该服务器自己的密钥。这条消息表示该服务器现在出示的是另一个密钥。如果你没有重建这台服务器，请不要为它批准任何操作：可能有别人在代替它应答。如果你确实重建了它，请在应用中用新的配方重新创建，让手机按正常流程认识它的新密钥。

flagshipserver.com 宕机了，而我需要用我的服务器

在与服务器相同的 Wi-Fi 下打开 iPhone 或 Android 应用。应用会在家庭网络中找到服务器并核对它的密钥，因此你仍然可以：

  1. 查看它的状态和应用。
  2. 启动、停止或重启某个应用，或者重启或关闭服务器。
  3. 创建备份并保存到手机上。

这只在服务器运行时有效。除非必要，请不要重启它：服务器重启后需要 flagshipserver.com 才能解锁磁盘。

浏览器提示“证书无效”

你的 TLS 证书存放在守护进程上，并会在到期前 30 天自动续期。如果你看到证书警告：

  1. 等待 90 秒。续期会静默地重新签发并重新加载。期间控制台会显示“正在续期”标记。
  2. 查看控制台的证书部分。如果显示“失败”，原因会在守护进程日志里。最常见的原因是续期窗口内盒子处于离线状态；在控制台手动触发一次续期即可解决。
  3. 全新安装、完全没有证书：首次签发在启动时进行，需要 30 到 60 秒。请刷新页面。

“403 非成员”或“服务已锁定”

服务默认受身份保护：只有所有者和被明确邀请的用户才能访问。如果你是所有者却看到 403：

  1. 确认你已在此设备上登录。打开 https://you.flagship.services/.flagship/ 的控制台；如果它要求配对，就完成配对。
  2. 如果你是被他人分享该服务的访客：请对方重新发出邀请。邀请令牌在首次使用后即失效。
  3. 如果该服务本应是公开的，请检查其清单中的 access 字段。所有者可以在控制台中修改。

每封邮件都由真人阅读。请发邮件至 support@flagshipserver.com，写明你试过什么、看到了什么，以及控制台 URL 或设备路径。通常一天内回复，如果你提到“blocked（被卡住）”会更快。
