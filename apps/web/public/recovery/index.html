Flagship recovery

This is your account's recovery page. It runs on its own separate address (recovery.flagshipserver.com), walled off from the rest of the site, so your recovery passkey can never be touched by anything else.

This window opens automatically from the Flagship webapp. If you got here directly, close this tab and click Set up cloud recovery (or Recover from passkey) inside the webapp.

Set up cloud recovery

Pick a recovery passphrase (8+ characters) — treat it like a password and write it down somewhere safe (a password manager, or paper in a drawer). You'll need this and your phone to recover on a new device. We cannot reset it if it's lost.

Recover from passkey

Enter your username and the recovery passphrase you chose when you set this up. We use them to retrieve your account key and unlock it with your passkey — all on this device. The passphrase never leaves your browser.

You're on recovery.flagshipserver.com — a separate address used only for recovery, so your passkey is kept apart from the main app. (Technical: rpId recovery.flagshipserver.com, passkey isolated by sub-origin.)
