Flagship recovery

A dedicated origin, isolated from the rest of the site.

This window opens automatically from the Flagship webapp. If you got here directly, close this tab and click Set up cloud recovery (or Recover from passkey) inside the webapp.

Set up cloud recovery

Pick a recovery passphrase. We use it to derive a fetch token (so flagshipserver.com won't hand out your wrapped key without it) and a per-user PRF salt (so a stolen passkey alone can't unwrap your UMK either).

Recover from passkey

Enter the username and the passphrase you set during enrolment. We re-derive the fetch token + PRF salt locally, fetch the wrapped UMK, then unlock it with your passkey.
