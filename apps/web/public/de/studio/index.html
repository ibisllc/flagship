Flagship Studio · Patent angemeldet

Baue deinen Server von deinem Computer aus.

Studio koppelt sich mit der Flagship-App, empfängt das Server-Rezept, das dein Telefon freigegeben hat, und schreibt den Boot-USB-Stick.

Öffne flagshipserver.com/studio auf dem Mac oder Windows-Computer, mit dem du den Server erstellen wirst.

Empfohlen für diesen Computer Für macOS herunterladen Apple Silicon und Intel · DMG Empfohlen für diesen Computer Für Windows herunterladen Experimentell Windows 11 · ZIP · noch nicht auf jedem PC erprobt
  1. Installiere und öffne Studio.

    Studio zeigt einen QR-Code und einen kurzen Kopplungscode.

  2. Kopple über dein Telefon.

    Wähle in der Flagship-App (App Store · Google Play) Server hinzufügen → Mit Studio koppeln und scanne dann den QR-Code oder gib den Kurzcode ein.

  3. USB-Stick schreiben und davon booten.

    Wähle in Studio das Ziellaufwerk. Dein Telefon genehmigt das Rezept; Studio kümmert sich um das Betriebssystem-Image und den USB-Stick.

Schon ein Rezept aus der Web-App heruntergeladen? Öffne es in Studio oder füge es dort ein. Unter Linux? Hol dir das AppImage Experimentell (x86-64; braucht Node.js 22 oder neuer).
