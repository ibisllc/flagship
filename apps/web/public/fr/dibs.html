Vous possédez le .com ? Réclamez votre nom en premier.

Chaque compte Flagship commence avec un nom aléatoire, et chacun peut passer à un nom de son choix. Pendant la première année, un nom qui correspond à un domaine .com enregistré est réservé à la personne qui contrôle ce domaine.

Comment ça marche

  • Uniquement le .com. Si vous contrôlez acme.com, vous pouvez réclamer le nom Flagship acme. Les autres extensions (.net, .org, domaines nationaux) ne donnent droit à aucune réservation.
  • Prouvez-le, une fois. Dans l’app, allez dans Réglages → Réclamer votre nom .com. Vous recevrez un code court à publier à l’un de ces deux endroits :
    • un enregistrement DNS TXT sur _flagship-claim.acme.com, ou
    • un fichier texte à l’adresse https://acme.com/.well-known/flagship-claim.
    Le code est lié à la clé de votre compte : personne d’autre ne peut le réutiliser.
  • La première preuve l’emporte. Si deux comptes prouvent le même domaine, la première réclamation vérifiée obtient le nom. Il n’y a pas de procédure d’appel.
  • 20 $, une seule fois. Réclamer un nom réservé coûte 20 $ (un changement de nom ordinaire coûte 10 $). Vos serveurs passent au nouveau nom avec vous.

Pour tous les autres

Vous pouvez acheter à tout moment n’importe quel nom libre qui n’est pas réservé au détenteur d’un .com, y compris pendant la période. À la fin de l’année, les noms réservés s’ouvrent à tous, premier arrivé, premier servi.

Pourquoi

Sur Flagship, un nom vous appartient pour de bon : nous n’en reprenons jamais. Donner une longueur d’avance aux détenteurs de domaines empêche quiconque de s’emparer du nom d’une marque avant qu’elle ait entendu parler de nous, sans que nous ayons jamais à juger qui mérite un nom.
