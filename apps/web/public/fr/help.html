Vous êtes bloqué. Voici ce qu’il faut essayer d’abord.

Des correctifs rapides pour les quatre problèmes les plus fréquents. Si aucun ne vous débloque, descendez en bas de page et écrivez à un humain.

Démarrage rapide

Je veux juste commencer.

  1. Installez l’app du téléphone depuis /download (ou utilisez l’app web).
  2. Sur un ordinateur, installez Flagship Studio.
  3. Créez un serveur dans l’app, associez-le avec le QR code ou le code court de Studio, puis utilisez Studio pour écrire la clé USB d’installation (8 Go ou plus).

Environ dix minutes jusqu’à un vrai cadenas vert sur you.flagship.services.

Bloqué à l’installation

Je suis bloqué sur l’écran d’installation.

  1. « Code d’association refusé » : rouvrez Studio pour afficher un nouveau QR code et un nouveau code court, puis réessayez.
  2. « Pas de réseau » : l’installateur a besoin de DHCP sur un port Ethernet filaire. Le Wi-Fi n’est pas pris en charge pendant l’installation. Branchez un câble.
  3. « Disque trop petit » : le minimum est de 32 Go. L’installateur formate le disque que vous lui indiquez ; il ne fait pas de double démarrage.

Toujours bloqué ? Capturez l’écran et envoyez-le-nous par e-mail.

Problèmes de téléphone

Mon téléphone est mort.

  1. Si vous avez activé le Trousseau iCloud ou Google Block Store lors de la configuration, connectez-vous sur le nouveau téléphone et votre identité se déballe avec la biométrie.
  2. Si vous ne l’avez pas fait, votre compte est irrécupérable ; c’est voulu (nous n’avons pas de porte dérobée) et nous avons essayé de le dire clairement pendant la configuration.
  3. Le matériel lui-même n’a rien. Créer un nouveau compte avec le même boîtier revient à une réinstallation propre.

Procédure de récupération complète : /docs/recovery.

Un service ne charge pas

Un service ne se charge pas.

  1. Le navigateur affiche « erreur DNS » : votre sous-domaine est en cours de propagation. Attendez 60 secondes ; consultez /status.
  2. « Certificat invalide » / pas de cadenas vert : le démon est en cours de renouvellement. Cherchez l’indicateur « Renouvellement » dans le tableau de bord ; cela se résout généralement en 90 secondes.
  3. « 403 non membre » : le service est protégé par l’identité et votre téléphone n’a pas approuvé votre appareil. Approuvez-le depuis le téléphone, puis actualisez.

Les journaux se trouvent sur votre boîtier, dans journalctl -u flagshipd.

Un peu plus, par symptôme.

Trois choses qui peuvent mettre hors ligne une installation qui fonctionnait. La plupart du temps, chacune se résout d’elle-même ; sinon, voici où regarder.

Mon installation reste bloquée sur « installé »

L’installation s’est terminée et le boîtier s’est éteint pour que vous puissiez retirer la clé USB et le rallumer, mais ensuite il ne démarre jamais. Cela signifie presque toujours que le boîtier n’atteint pas le réseau au début du démarrage et ne peut donc pas récupérer la clé qui déverrouille son disque chiffré. C’est le symptôme habituel sur un boîtier Wi-Fi uniquement (l’étape de déverrouillage du disque s’exécute avant que le Wi-Fi soit disponible). Deux solutions :

  1. Branchez un câble Ethernet. Une connexion filaire est active assez tôt pour que le boîtier récupère sa clé de déverrouillage et termine son démarrage. C’est la solution la plus simple et elle garde votre disque chiffré.
  2. Ou créez un nouveau serveur avec le chiffrement du disque désactivé. Dans l’écran « Créer un serveur » de l’app (ou de l’app web), décochez Chiffrer le disque, puis regravez. Un boîtier au disque non chiffré démarre sans avoir besoin du réseau pour se déverrouiller, il fonctionne donc avec des installations en Wi-Fi uniquement. Le compromis : vos données ne sont plus chiffrées au repos, ce qui est moins sûr si le boîtier est volé. Ne choisissez cette option que si une connexion filaire est impossible.

Le tableau de bord indique « Hors ligne »

Le tunnel entre votre boîtier et flagship.services est coupé. Vérifiez, dans l’ordre :

  1. Alimentation et réseau. Le boîtier est-il allumé ? Le câble est-il branché ? Atteint-il Internet (ping 1.1.1.1) ?
  2. Le port 443 sortant est joignable. Certains réseaux restrictifs bloquent les WebSockets de longue durée. curl https://flagship.services/api/health depuis le boîtier doit renvoyer du JSON.
  3. Santé du démon. Connectez-vous en SSH et lancez systemctl status flagshipd. Redémarrez avec systemctl restart flagshipd ; journaux récents dans journalctl -u flagshipd -n 200.

« Certificat invalide » dans le navigateur

Votre certificat TLS vit sur le démon et se renouvelle automatiquement 30 jours avant son expiration. Si vous voyez un avertissement de certificat :

  1. Attendez 90 secondes. Les renouvellements se réémettent et se rechargent silencieusement. Le tableau de bord affiche un indicateur « Renouvellement » pendant ce temps.
  2. Consultez la section certificat du tableau de bord. Si elle indique « Échec », la cause se trouve dans le journal du démon. Le motif le plus courant : le boîtier était hors ligne pendant la fenêtre de renouvellement. Déclencher un renouvellement manuel depuis le tableau de bord règle le problème.
  3. Nouvelle installation sans aucun certificat : la première émission a lieu au démarrage et prend de 30 à 60 secondes. Actualisez.

« 403 non membre » ou « Service verrouillé »

Les services sont protégés par l’identité par défaut : seuls le propriétaire et les utilisateurs explicitement invités peuvent y accéder. Si vous êtes le propriétaire et voyez un 403 :

  1. Vérifiez que vous êtes connecté sur cet appareil. Ouvrez le tableau de bord sur https://you.flagship.services/.flagship/ ; s’il demande une association, associez.
  2. Si vous êtes un invité avec qui quelqu’un a partagé le service : demandez-lui de réémettre l’invitation. Les jetons d’invitation expirent après le premier usage.
  3. Si le service est censé être public, vérifiez le champ access de son manifeste. Le propriétaire peut le modifier depuis le tableau de bord.

Je veux parler à un humain.

Une vraie personne lit chaque e-mail. Écrivez à support@flagshipserver.com en indiquant ce que vous avez essayé, ce que vous avez vu, et l’URL du tableau de bord ou le chemin du périphérique. Réponse généralement sous un jour, plus vite si vous mentionnez « bloqué ».
