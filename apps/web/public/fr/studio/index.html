Flagship Studio · Brevet en instance

Créez votre serveur depuis votre ordinateur.

Studio s’associe à l’app Flagship, reçoit la recette de serveur autorisée par votre téléphone et écrit la clé USB de démarrage.

Ouvrez flagshipserver.com/studio sur le Mac ou l’ordinateur Windows ou Linux que vous utiliserez pour créer le serveur.

Recommandé pour cet ordinateur Télécharger pour macOS Apple Silicon et Intel · DMG Recommandé pour cet ordinateur Télécharger pour Windows Expérimental Windows 11 ou Windows 10 22H2 · ZIP · pas encore éprouvé sur tous les PC Recommandé pour cet ordinateur Télécharger pour Linux Expérimental x86-64 · AppImage · nécessite Node.js 22 ou plus récent, pkexec et xorriso
  1. Installez et ouvrez Studio.

    Studio affiche un QR code et un code d’association court.

  2. Associez depuis votre téléphone.

    Dans l’app Flagship (App Store · Google Play), choisissez Ajouter un serveur → Associer avec Studio, puis scannez le QR code ou saisissez le code court.

  3. Écrivez la clé USB et démarrez dessus.

    Choisissez le disque cible dans Studio. Votre téléphone approuve la recette ; Studio s’occupe de l’image du système d’exploitation et de la clé USB.

Vous avez déjà téléchargé une recette depuis l’app web ? Ouvrez-la ou collez-la dans Studio.
