Quick start

Three steps. About ten minutes.

1. Install the phone app. Pick a username. Approve biometrics. Your master key never leaves the phone.

2. Generate a build code. Either order a pre-built box or paste the code at /build to download a personalized installer ISO. Flash, plug in, boot.

3. Vibe-code your first app from the phone. Or install someone else's. Done.

Architecture

Three planes. flagshipserver.com handles identity. flagship.services is a stateless pipe (SNI passthrough + tunnel hub). Your box terminates TLS itself with a real Let's Encrypt cert. We literally cannot read your data.

The phone holds your keys. The .com Worker is the registrar; it never sees plaintext content. The .services Fly app is a dumb router that sees encrypted bytes only.

Install & first boot

The installer is a public shell script in our open-source repo. It's pinned by hash inside the build code blob. The installer formats the disk with LUKS, generates a server identity, requests a Let's Encrypt cert via DNS-01, and registers with .com.

Every subsequent boot, the phone has to approve the LUKS unlock. A stolen box without your phone is a brick.

Phone pairing

To use the web console you scan a QR code from the phone. The phone mints a 32-byte session token, signs an add-paired-session order, and the daemon stores the token. The browser holds it as a cookie; every admin call carries it.

Pairings are listed in Settings → Paired devices. Revoke any time.

Apps & manifest

An app is a Docker container with a flagship.app.json manifest. The manifest declares which data stores the app needs (Postgres, MinIO, Redis), which web hosts it can navigate to, and what's public. The daemon injects identity headers so apps never have to handle login.

You vibe-code an app from the phone (the LLM emits the manifest + Dockerfile + sources) or you write it by hand and push to your Forgejo. Either way the daemon builds, deploys, and routes.

URL multiplexing

When you have one install of game, the URL game.john.flagship.services just works. When you have two installs of game on different boxes, that short URL is ambiguous and we serve a disambiguation page. The full long form (game.home.john.flagship.services) always works.

You declare and release short-URL aliases from the phone. Full design →

Recovery

If you backed up to iCloud Keychain or Google Block Store at setup, a fresh phone can recover your master key with biometrics. If you didn't, your data is gone — like a hardware wallet. We tell you this clearly during setup.

API reference

The .com Worker exposes an extensive API for build codes, server registration, marketplace, push, LLM-promo, and aliases. The daemon exposes a per-app surface (browser, alerts, identity rotation, app install/uninstall).
