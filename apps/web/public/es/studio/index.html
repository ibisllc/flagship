Flagship Studio · Patente en trámite

Crea tu servidor desde tu ordenador.

Studio se vincula con la app de Flagship, recibe la receta del servidor que autorizó tu teléfono y graba el USB de arranque.

Abre flagshipserver.com/studio en el ordenador Mac, Windows o Linux que usarás para crear el servidor.

Recomendado para este ordenador Descargar para macOS Apple Silicon e Intel · DMG Recomendado para este ordenador Descargar para Windows Experimental Windows 11 · ZIP · aún no probado en todos los PC Recomendado para este ordenador Descargar para Linux Experimental x86-64 · AppImage · necesita Node.js 22 o posterior, pkexec y xorriso
  1. Instala y abre Studio.

    Studio muestra un código QR y un código de vinculación corto.

  2. Vincúlalo desde tu teléfono.

    En la app de Flagship (App Store · Google Play), elige Añadir servidor → Vincular con Studio y luego escanea el QR o introduce el código corto.

  3. Graba y arranca el USB.

    Elige la unidad de destino en Studio. Tu teléfono aprueba la receta; Studio se encarga de la imagen del sistema operativo y del USB.

¿Ya descargaste una receta desde la app web? Ábrela o pégala en Studio.
