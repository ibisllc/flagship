Report abuse

If a *.flagship.services subdomain is hosting malware, phishing, copyright infringement, or other abuse, contact us and we will investigate and take action.

Contact

  • Email: abuse@flagship.services
  • Authorized representative: Flagship Abuse Team (flagshipserver.com)

What to include

  • The full URL or hostname (e.g. something.example.flagship.services).
  • A short description of the abuse (phishing, malware, CSAM, copyright, harassment, etc.).
  • Evidence — screenshots, headers, sample URLs, or a reference to a third-party report (Google Safe Browsing, PhishTank, NCMEC, etc.).
  • Your contact info if you would like an acknowledgement and resolution update.

Response targets

  • Acknowledge within 2 business days.
  • CSAM and active phishing escalated immediately on receipt.
  • Other categories triaged within 5 business days.

What we can do

Each Flagship server runs on hardware the user owns; user content is end-to-end private to that user (TLS terminates on their machine, not on our infrastructure). What we control is the routing layer: we can revoke a subdomain's routing entry on flagship.services, which removes the abusive site from the public internet, and we can revoke the user's identity on flagshipserver.com.

We cannot read the content of a user's TLS-encrypted traffic, so requests for content monitoring or interception cannot be honored — by design.

Security vulnerabilities

For security issues in Flagship itself (the protocol, daemon, control plane, or clients), please use the security disclosure process instead.
