Install

Recommended Linux images.

Flagship Assembler builds your boot drive on top of a stock Linux installer. We test against a small, pinned list — use one of these for a clean, verified install.

Ubuntu Server 22.04.5 LTS amd64 · recommended

The long-term-support server image. Boots on both BIOS and UEFI machines. This is the image the Assembler is tested end-to-end against today.

Why a pinned list?

The Assembler verifies the image's SHA-256 against this list before it writes anything. If the bytes don't match — a corrupted download, a tampered mirror, or simply a version we haven't tested — it refuses to continue. You never have to copy a checksum by hand; the check is automatic. We add images here only after a real end-to-end install on real hardware.
