Flagship Studio

Build your server from your computer.

Studio pairs with the Flagship app, receives the server recipe your phone authorized, and writes the boot USB.

Open flagshipserver.com/studio on the Mac or Windows computer you will use to create the server.

Recommended for this computer Download for macOS Apple Silicon and Intel · DMG Recommended for this computer Download for Windows Windows 10 and 11 · EXE
  1. Install and open Studio.

    Studio shows a QR code and a short pairing code.

  2. Pair from your phone.

    In Flagship, choose Add server → Pair with Studio, then scan the QR or enter the short code.

  3. Write and boot the USB.

    Choose the target drive in Studio. Your phone approves the recipe; Studio handles the operating-system image and USB.

Already downloaded a recipe from the webapp? Open or paste it in Studio. Linux support is coming later.
