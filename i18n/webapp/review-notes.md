# Strings that need a native reader before a language ships

Added with the release/0.3 security strings. Machine drafts.

- The same new terms as Android (`i18n/android/review-notes.md`): boot service, lock / remote lock, resume, publisher.
- "{0} sent; locked" and "{0}; {1}." join an action label or a power result with a lock result; check both halves read as one sentence.
- "It becomes active {0} unless an admin rejects it" is filled with "on {date}" or "as soon as it finishes"; check both read naturally.
