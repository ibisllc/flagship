# Strings that need a native reader before a language ships

Added with the release/0.3 security strings. Machine drafts.

- The same new terms as Android (`i18n/android/review-notes.md`): boot service, lock / remote lock, resume, publisher.
- "{0} sent; locked" and "{0}; {1}." join an action label or a power result with a lock result; check both halves read as one sentence.
- "It becomes active {0} unless an admin rejects it" is filled with "on {date}" or "as soon as it finishes"; check both read naturally.

Added with voi.ci pages + Messages (release 0.3 H11, webapp chunk F). Machine drafts; these need a native reader first:

- The page warning ("Anyone can see this page. It shares your username with your apps and servers, so people can
  connect them."), the "Page and message rules" text, and the report sheet ("Flagship gets the message and can see
  which account sent it, not what it says.") carry a promise about privacy and moderation: check nothing is softened.
- "Visitor {0}" is a generated name, never a person's; "{0} change(s) not published" counts page changes.
- "Too many tries. Try again {0}." and "You've started as many new conversations as you can today. Try again {0}." are
  filled with a relative time ("in 12 minutes", "tomorrow"); check both read naturally.
- Theme names Classic / Ink / Sea are the page's three looks; keep them short.
